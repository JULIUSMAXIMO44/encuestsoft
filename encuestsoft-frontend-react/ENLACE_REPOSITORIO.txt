ENLACE DEL REPOSITORIO — EncuestSoft (React JS)
================================================

Este proyecto incluye un repositorio Git local ya inicializado (ver carpeta
.git/ y el historial de commits). Como el entorno donde se generó este
proyecto no tiene acceso a internet, el repositorio remoto (GitHub/GitLab)
debe crearse y publicarse manualmente antes de la entrega:

1. Crea un repositorio vacío en GitHub o GitLab (por ejemplo:
   encuestsoft-react).
2. Desde la carpeta del proyecto, ejecuta:

     git remote add origin https://github.com/JULIUSMAXIMO44/encuestsoft.git
     git branch -M main
     git push -u origin main

3. Reemplaza la siguiente línea con la URL real de tu repositorio:

Enlace del repositorio: https://github.com/JULIUSMAXIMO44/encuestsoft.git
